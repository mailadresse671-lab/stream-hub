# Szenen-Ordner

Hier liegen die kanonischen Quellordner fuer komplette Szenen-Sammlungen.

Aktuell vorhanden:
- `core/` — kanonische Quellseiten der Hauptszenen ausserhalb der Oldschool-Suite
- `oldschool/` — komplette 90s-Old-School-Suite

Geplante Regel fuer kuenftige Struktur:
- Jede neue zusammengehoerige Szenen-Suite bekommt hier einen eigenen Unterordner.
- Root-Dateien duerfen als stabile Einstiegspfade fuer Streamlabs/Vercel bestehen bleiben.
- Inhaltliche Arbeit soll in den Suite-Ordnern passieren, nicht in Legacy-/Wrapper-Dateien.

Hinweis:
- Die Root-Dateien bleiben bewusst als stabile Einstiegspfade fuer Streamlabs/Vercel erhalten, auch wenn die kanonischen Quellseiten bereits unter `scenes/` liegen.
