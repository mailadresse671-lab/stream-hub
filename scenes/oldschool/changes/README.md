# Aenderungen

Hier kommen kuenftig strukturierte Notizen, Varianten oder gezielte Change-Artefakte zur Oldschool-Suite hinein, wenn eine Szene groessere Umbauten oder alternative Versionen bekommt.

Regel:
- Laufende Produktionsdateien bleiben direkt eine Ebene hoeher in `scenes/oldschool/`.
- Nur Zusatzmaterial, Varianten, Vergleichsnotizen oder temporare Migrationshilfen kommen in diesen Unterordner.
