# Widgets

Dieser Ordner reserviert die kuenftige saubere Heimat fuer frei positionierbare Einzel-Widgets.

Kanonische Widget-Quellen liegen jetzt hier:
- `avatar.html`
- `rl-stats.html`
- `rl-daily.html`
- `rl-rank-frame.html`
- `status-ticker.html`
- `event-cards.html`
- `chat-vibes.html`
- `hype-level.html`
- `status-bar.html`

Die gleichnamigen Root-Dateien bleiben als stabile Browser-Quellen-Einstiege erhalten und leiten hierher weiter.

Zielbild:
- Inhaltliche Widget-Aenderungen immer hier machen.
- Root-Dateien nur als Kompatibilitaets-Einstiege behandeln.
